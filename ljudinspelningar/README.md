# Ljudinspelningar

Detta arkiv innehåller historiska ljudinspelningar publicerade av
Haninge Hembygdsgille.

Själva MP3-filerna distribueras som GitHub Release-assets. Repositoryt
innehåller kataloginformation, metadata, källhänvisningar och
kontrollsummor.
